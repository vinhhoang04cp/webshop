fix: Google OAuth redirect loop trong Docker environment

🐛 Vấn đề:
- Đăng nhập qua Google OAuth bị redirect loop về trang login
- Sau khi clear cache thì lại hoạt động
- Chỉ xảy ra trong môi trường Docker

🔧 Nguyên nhân:
1. SESSION_SAME_SITE=strict chặn cookies từ OAuth redirect
2. SessionSecurityMiddleware phát hiện sai session hijacking
3. Config cache không được clear tự động

✅ Giải pháp:
1. .env:
   - Đổi SESSION_SAME_SITE=strict thành lax
   - Thêm TRUSTED_PROXIES=* cho Docker nginx proxy

2. SessionSecurityMiddleware.php:
   - Thêm method isOAuthCallback() để detect OAuth routes
   - Skip security checks cho auth/*/callback routes
   - Tránh false positive khi redirect từ OAuth provider

3. clear-cache.sh:
   - Script tự động clear cache trong Docker container
   - Dễ dàng áp dụng config changes

4. Dockerfile:
   - Auto clear cache khi rebuild container
   - Đảm bảo không có stale config
