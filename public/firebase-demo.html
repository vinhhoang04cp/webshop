Setup Instructions

  1. Firebase Setup:
    • Tạo project mới trên Firebase Console
    • Bật Authentication và cấu hình Google provider
    • Thêm domain vào Authorized domains
    • Copy config và thay thế trong resources/js/firebase/auth.js
  2. Laravel Setup:
    • Download Service Account Key từ Firebase Console
    • Cập nhật file .env với Firebase credentials
    • Chạy: ./vendor/bin/sail artisan migrate
  3. Frontend Setup:
    • Cài đặt Firebase SDK: npm install firebase
    • Import và sử dụng FirebaseAuthService
